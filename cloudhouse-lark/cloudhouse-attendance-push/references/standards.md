# 考勤推送口径与文案标准

用户多次裁定后的定稿标准。脚本参数化实现；本文是口径权威，改口径先改本文。

## 统计窗口

- **自然周周一~周日**（"上周"）。计算：last_monday = today - timedelta(days=today.weekday() + 7)。
- 不含导出当天；**禁止**加"截至导出时点/导出当日"类标注（用户明确反感）。
- 窗口由 `--start/--end` 传入，脚本不硬编码日期。

## 时长算法

- 打卡规则为上下班交替：当日 `HH:MM` 串升序后两两配对 (1,2),(3,4)… 求差累加；**末尾孤立卡忽略**（审计留痕）。
- 无记录/`-` = 0；整数分钟累加；展示 `ROUND_HALF_UP` 保留 1 位；总工时=窗口原始分钟和一次舍入（每日展示值各自舍入，其和与总工时或差 ±0.1，属正常）。
- **交叉验证门**：全表范围重算 vs「实际出勤时长(小时)」列，偏差须 ≤0.05h；超差即中止，向用户确认差异原因（总时长列可能含无打卡记录的修正，如补卡批准），经确认后以 `--known-correction 姓名=小时` 传入，不得静默忽略或擅自取数。
- **双倍规则**：默认 `26软件打卡` 组晚 20:00–23:00 重叠部分双倍计入总工时（`--double-group/--double-range` 可调）。成员卡**标注在每日工时行**（如「4.2 小时（其中 2.3 小时双倍计入）」），总工时行不加注；**组长卡不标注双倍**。

## 显示与措辞

- 无记录日显示 **0.0 小时**。
- 零工时成员总工时行："**总工时**：本区间暂无打卡记录，总工时 0.0 小时；如有疑问请联系考勤负责人。"

## 成员卡文案

- 标题：`【假勤】上周考勤摘要（M.D-M.D）`（不补零）；header.template=blue。
- 正文首块：`**姓名**：X\n**考勤组**：Y\n**统计区间**：YYYY-MM-DD ~ YYYY-MM-DD\n**总工时**：**Z 小时**`。
- 次块：`**每日工时**` + 每日行 `- MM-DD 周X：N.N 小时[（其中 B.B 小时双倍计入）]`。
- 底部灰色三行（用户指定原文，含分号；链接用运行时解析的考勤规则 URL）：
  `数据来源：飞书假勤；` / `考勤规则：<RULES_URL>；` / `如有疑问，请联系组长，谢谢；`
- 不加其他元信息（口径说明、范围说明、修正版标记等一律不要）。

## 组长卡文案

- 标题：`【假勤】<组显示名>上周考勤报告（M.D-M.D）`。
- 首块：`**考勤组**：<考勤组值>\n**每周要求**：N 小时\n**达标情况**：X/Y 人达标`。
- 成员明细行：`- 姓名：Z 小时——达标` 或 `——未达标（差 G 小时）`。
- 底部灰色两行：数据来源 + 考勤规则链接（无"联系组长"行）。
- **达标线运行时从考勤规则文档读取**（示例：创盟/算法 10h、软件/硬件/设计 15h），不硬编码。
- 收件人=各组考勤负责人/组长：以规则文档「考勤负责人」与名册 Base「负责人信息」交叉一致为准。

## 映射与收件

- 成员=考勤表内全部人；组长报告覆盖表内该组成员。
- 名册 Base **全量读取，省略 `--view-id`**（带视图的本地快照是过滤子集，不可当全量）；投影姓名字段精确匹配。
- 缺失/同名冲突：`contact +search-user --queries` 兜底、按部门消歧；仍缺问用户，**不擅自跳过**；映射齐全才批量。

## 发送与审批

- **硬闸门**：成员推送与组长推送各自先发给请求者一张样板（正式格式、真实数据），回读核对+用户目视，获明确批准后才批量；改参后重走样板。
- 卡片 JSON 必须 `"schema":"2.0"`（省略→客户端空 body；"2.0.0"→报错）；`--content @file` 免转义。
- 幂等键：成员 `att-<窗口止MMDD>-r<行号>`；组长 `att-leader-<窗口止MMDD>-<key>`；窗口变更键随之变更。
- 串行、间隔 ≥0.5s；逐条 ndjson 留痕；失败分类（可见范围→列清单待管理员修复后原键补发；ID 无效→回映射；限流→退避重试一次），不静默跳过。
- 批量后 `im +messages-mget` 全量回读（≤50/次）：sender 为 bot、未撤回、body 含本人姓名/组名与总工时。

## 陷阱表

| 陷阱 | 规则 |
|---|---|
| schema 省略/2.0.0 | 必须精确 "2.0"，发送前静态校验 |
| 视图过滤快照 | 名册读取省略 --view-id，核对 manifest has_more |
| 人员字段 name 快照 | 可能过时，冲突以 contact 实时为准 |
| bot 私聊可见范围 | 目标须在应用可见范围，失败收集汇报 |
| 配额 99991403 | 立即停止，不循环重试 |
| 总时长列修正 | 交叉验证超差先问用户，--known-correction 显式传入 |
